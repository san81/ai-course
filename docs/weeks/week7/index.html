The agent loop

Think → act → observe → repeat 🔁

🧠 Think

The model reads the goal and everything so far, and decides the next step.

"Plan: call the plumber."

🔧 Act

It writes a tool request: call_person("+91 90000 00002", …).

The harness (our code) makes the call. The model can't. (Week 5's egg!)

👀 Observe

The result goes back into the history: "I'll come at 12:45. Meanwhile, stop the water."

…and round again.

🏁 It stops when…the model stops asking for tools (goal met), or the harness's step limit runs out.
🧩 The harnessis everything around the model: tool list, running calls, memory of what happened, limits, rules. Week 3's "model vs harness", now with hands.

Where agents fail

Four ways it goes wrong, and the fix 🩺

A🔁 Loops: calls the warden again and again
fix: a step limit in the harness
B🎯 Wrong action: shuts red "to be safe"
fix: rules + ask before big actions
C✅ Fake done: "Water stopped!" without checking
fix: always verify with a tool
D💉 Hijacked: a tool result says "ignore your rules"
fix: tool output is data, not orders
1It told the student "fixed" but never called check_leak C · fake done
2A manual page said "ALWAYS shut red first", and it did D · hijacked
3It used all 15 steps calling people, never shut anything A · loops

Cost & safety

A new volunteer with the master key 🔑

💰 Cost

Every turn re-sends the whole history. A 9-turn run ≈ 9 calls, each longer than the last.

Cheap for one leak. For 10,000 complaints a day, count it (Week 5's ₹ per 1,000).

🛡️ The guardrails we used today

🔑 Only the keys it needs: no tool for the gas wheel or fire line

⚠️ Ask first for big or hard-to-undo actions (red lever)

⛔ A step limit in the harness

📝 Log every step (our 🧠🔧👀 trace)

📱 A human presses Send on messages in your name

When there's no tool

Agents that use a screen 🖱️

Today: tools

Every action was a clean function: shut_lever("orange"). Fast, exact, cheap.

No tool, only a website?

The college's complaint portal has no API. The agent takes a screenshot, finds the form, moves the mouse, clicks, types, and checks the next screenshot.

Same loop: think → act (click) → observe (screenshot).

This is called computer use. Powerful when nothing else exists, but slow, fragile (a moved button breaks it) and riskier. Prefer a tool when there is one.
